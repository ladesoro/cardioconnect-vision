# CardioConnect Vision

A future-state product vision for Boston Scientific’s CardioConnect field scheduling and operations experience.

This project is a static, interactive prototype that explores how CardioConnect can evolve from a shared scheduling and assignment foundation into a connected, intelligent operating layer for cardiology field teams.

## What this site communicates

- The vision is built around the idea that scheduling can become the front door to readiness, documentation, and smarter field action.
- It illustrates four core workflow moments: **Anticipate**, **Orchestrate**, **Prepare**, and **Complete**.
- It also includes bonus future workflows like **Balance Coverage** and **Act on Insight**.
- It maps a maturity journey from **Fragmented coordination** through the current **Visible MVP foundation** to a **Connected case lifecycle** and ultimately an **Intelligent, AI-assisted operating model**.

## Why it matters

- The MVP validates a shared scheduling layer for field access, assignment visibility, and mobile team coordination.
- The vision highlights how CardioConnect can extend beyond schedule viewing to support case readiness, procedure documentation, inventory readiness, and leadership visibility.
- It emphasizes practical implementation thinking: preserve existing systems, integrate where needed, and enable advanced capabilities only when data, workflow, and governance are ready.

## Key ideas

- Shared scheduling visibility establishes a common intake and assignment experience across cardiology field teams.
- Connected workflows reduce friction by carrying case context, inventory details, and physician information through to the procedure record.
- Intelligent operations support risk anticipation, capacity balancing, proactive recommendations, and account-level insights.

## Project structure

- `index.html` — the main prototype page and content source.
- `assets/` — media assets, workflow videos, and visual assets used in the prototype.
- `archive/` — earlier versions of the concept.

## Notes

This repository is intended as a design and vision artifact rather than a production application. It is useful for communicating strategy, roadmaps, and field operations thinking for CardioConnect’s next horizon.
